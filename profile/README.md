## A passion project, built with the community. led by [dodo986](https://github.com/dodo986)

Svara is a Linux project focused on building a distinctive, high-performance desktop experience. Built around Fedora's image-based system architecture, Svara aims to combine the flexibility power users expect with the extreme stability and reliability of an immutable operating system.

We believe a desktop should be more than a collection of applications and configuration files. It should feel cohesive, responsive, and intentional — from the underlying system to the smallest details of its interface.

Svara is a work in progress, built through experimentation, learning, and community participation. Ideas, bug reports, documentation, testing, and code contributions are all welcome. What we can maintain and deliver depends on the time and people available, and community participation does not imply guaranteed support or that every request will be accepted.

## The Svara experience

Svara is designed for power users, desktop customization enthusiasts, and gamers who want a carefully crafted Wayland experience without giving up system reliability.

Its visual identity draws from ancient Slavic motifs and Celtic knotwork, reinterpreted through a modern, gothic design language. Interwoven forms, deliberate motion, and connected surfaces help shape an interface that feels like a unified whole rather than a collection of unrelated panels.

The desktop is built to be deeply customizable, with performance and usability treated as essential parts of the experience rather than afterthoughts.

Svara uses Fedora's bootc image-based architecture as its system foundation, embracing image-based updates and deployment-based rollback workflows. Applications and user-space tooling are handled separately where appropriate, helping preserve the integrity of the underlying system.

Svara is actively evolving. Features, requirements, and supported workflows may change as development progresses; consult the relevant project documentation before installing or relying on a feature.
